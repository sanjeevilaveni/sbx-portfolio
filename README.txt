# SBX Website — Free Hosting

This is a ready-to-publish static website.

## Free option: GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, for example `sbx-portfolio`.
3. Upload `index.html` and the `assets` folder.
4. Open Settings → Pages.
5. Select **Deploy from a branch**, choose `main` and `/root`, then Save.
6. GitHub will give you a free `github.io` website address.

## Important
Before publishing, replace `hello@sbx.example` in `index.html` with your real business email.

The website is responsive and works on mobile and desktop.
